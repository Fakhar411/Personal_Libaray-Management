Personal Library Management System

A simple and lightweight Library Management System built using Python and CSV (Comma-Separated Values) file storage. This system allows users to add, view, search, update, and delete books in their personal collection using a command-line interface (CLI).


---

🚀 Features

✔ Add Books – Store book details (ID, title, author, genre, year).
✔ View Books – Display a list of all books in the library.
✔ Search Books – Find books by title or author.
✔ Update Books – Modify existing book details.
✔ Delete Books – Remove books from the collection.
✔ No Database Required – Uses a simple CSV file for storage.
